# 대시보드 검증

- 상태 분류 회귀 테스트: `node --test tests/dashboardTasks.test.mjs`
- 타입 검사 및 운영 빌드: `npm run build`
- 로컬 화면: `npm run dev` 후 `/tests/dashboard-preview.html`

로컬 화면은 기존 목업 자료를 사용하며 API 요청, 구매 승인, 메일 발송을 하지 않습니다.
사람 확인 / 시스템 처리 / 외부 응답·입고 대기를 상호 배타적으로 분류합니다.
더보기, 개별 상세 펼치기, 실제 업무 화면으로 전달되는 탭·MR 번호를 확인할 수 있습니다.
이 HTML은 Vite 운영 빌드의 진입점이 아니므로 운영 사이트에는 배포되지 않습니다.

운영 대시보드는 기존 케이스 조회와 SSE 갱신, DB 알림함을 재사용합니다.
별도 주기 조회나 AI 호출은 추가하지 않습니다. 최근 알림은 감사 이력 전체가 아니며,
알림함에서 삭제한 내용은 여기에 나타나지 않습니다.
진행률은 실행률을 추정하지 않고, 견적 회신율에 한해 서버 값을 표시합니다.
PO 금액은 조회된 고유 발주서 합계이며 월별 매출/발주액으로 표시하지 않습니다.
