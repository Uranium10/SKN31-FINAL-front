# 작업 목록 표 정리 — 2026-09-28

## 사용자 변경점

- 대시보드: 결정 대기·외부 응답 대기 행의 왼쪽을 낮은 채도의 노란색으로 표시. 점검 필요의 빨간색은 우선 유지.
- MR·협력사 선정·PO: 표 헤더가 본문 스크롤 영역 상단에 고정됨. 가로 스크롤도 본문과 함께 이동.
- 협력사 선정·PO: 컬럼 헤더를 드래그하여 재배치. 헤더에 키보드 초점을 두고 Alt+좌우 방향키로도 이동 가능.
- 레이아웃 초기화 버튼: 컬럼 순서·너비·필터·정렬을 초기화. 취향값은 기존과 같이 탭의 sessionStorage에 저장되며 서버 데이터는 바꾸지 않음.
- PO 납기: YYYY-MM-DD, 실제 시간값이 있으면 HH:mm까지 표시. 명시적 시간대가 있는 값은 한국 시간으로 변환. 날짜만 있는 값에 00:00을 만들어 넣지 않음.
- 협력사 선정: 회신율과 진행상태를 ‘상태 / 진행’으로 통합. RFQ 발송 → 견적 수집 → 업체 선정 단계와 회신 수·비율·비교 바로가기를 함께 표시.
- 회신율 필터는 상단의 전체 / 50% 이상 / 50% 미만 선택으로 유지. 상태·마감 필터는 헤더에 유지.
- 차수는 일반 텍스트, 마감은 D-n / D-day / D+n 작은 태그. 임박·경과 때만 제한적으로 색 사용.
- 협력사 선정의 진행중/완료 탭 제거: 진행중 데이터만 표시. 완료 데이터나 DB 이력은 삭제하지 않음.

## 구현

`SmartTableContainer.tsx`의 `stickyHeader` 옵션이 실제 thead 위치를 프레임당 한 번 측정해 이동시킴.
가로 overflow가 있는 래퍼는 CSS sticky만으로 바깥 .view-content 스크롤을 따라가지 못하기 때문에
원본 헤더를 이동하며 복제하지 않음. 필터·드래그·키보드 포커스는 원래 컴포넌트에 그대로 유지.
테이블 끝을 벗어나지 않도록 이동 거리를 제한하고, 언마운트 시 이벤트와 관찰자를 해제.

`useTableColumnOrder.ts`가 저장된 순서를 검증하고, `OrderedTableRow.tsx`가 실제 td 순서를 맞춤.
열 정의 / colgroup / th / td에 동일한 순서를 사용하고 그 정의를 `useSessionTableState`에 전달하므로
순서 변경 후에도 인접 리사이즈 대상이 일치. 기존 최소 폭과 표의 좌우 끝 고정 로직은 유지.
삭제된 컬럼 키와 중복 키는 저장값에서 걸러내고 새 컬럼은 누락 없이 추가.

협력사 선정의 이전 ‘견적 요청상태’ 필터는 새 상태명으로 변환하여 배포 후 행이 숨겨지는 상황을 방지.
기존 회신율 다중 선택값은 새 단일 선택 UI와 일치하도록 정규화.
승인·발송·재비딩·취소 조건과 핸들러, 백엔드 API·권한·TEST_MODE·메일 설정은 변경하지 않음.
